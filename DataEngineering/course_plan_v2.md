# Data Engineering Lead — Interview Prep Course (v2)

## Constraints

| Item | Value |
|---|---|
| Learner | Software Engineering team lead (5 years of management, last coded in 2018) |
| Target | Data Engineering Team Lead interviews, Swiss pharma |
| Total time | **4 hours** |
| Coding | None |
| Format | Interactive web app (`app/`), private, English |
| Feedback | Built-in feedback (auto-graded checks, scenarios, rubrics + model answers); AI feedback optional |
| Assessment | The same 24-question quiz at the start and at the end, with a comparison |

## Flow (240 min)

| # | Step | Min |
|---|---|---|
| 0 | Baseline quiz (24 questions, 3 per module, "I don't know" allowed, no answers shown) | 15 |
| 1 | From software to data engineering | 15 |
| 2 | Storage & data modeling | 25 |
| 3 | Pipelines & integration | 25 |
| 4 | Architecture & platforms | 25 |
| 5 | DataOps & reliability | 25 |
| 6 | Governance, GxP & privacy | 30 |
| 7 | Data for ML & AI | 25 |
| 8 | Leading a data team (org, hiring, prioritization, cost, 90 days) | 25 |
| 9 | Interview rehearsal (open questions with rubrics) | 15 |
| 10 | Final quiz (same 24 questions) → before/after comparison per module and per question | 15 |

## Module structure

1. **Bridge** — "you know X from software; in data it differs because Y".
2. **Concepts** — short, manager-level, with pharma examples (GMP manufacturing, QC labs, clinical, pharmacovigilance).
3. **Scenario** — a 3–4 step decision game with feedback on every option.
4. **Check** — 3 auto-graded questions (different from the quiz questions).
5. **Lead's lens** — the decisions a lead owns and what interviewers listen for.
6. **Interview question** — open answer → self-assessment against a rubric → model answer (→ optional AI grading).

## Changes from the initial plan

- 6 weeks → 4 hours: concepts stay at the level needed to discuss and challenge, not to operate.
- Tool exploration (Databricks, Airflow, dbt, …) is replaced by scenarios. Tools are named in context only.
- ML algorithms are replaced by "data for ML & AI" (what a data engineering team owns).
- Added: data contracts, backfills, data observability, the vendor landscape, FinOps, GxP data integrity (ALCOA+, Part 11, Annex 11/22, GAMP 5, CSA), Swiss revFADP / HRA, hiring, and request intake.
- Lambda/Kappa is reduced to a historical note; Data Mesh is presented as an organizational pattern with its failure modes.
